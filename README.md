# No Power Drains: Improved

Configurable changes to electric idle drain, roboport power, beacons and radar scanning costs.

**Factorio 2.1 · Version 1.0.1**

- Assemblers, electric furnaces, inserters, pumps and electric turrets retain their working power cost.
- Roboport energy usage can be removed; robot charging energy is unchanged.
- Beacon and radar options retain a 1 W minimum.
- Vision-only radar mode leaves long-range scanning radars unchanged.

## Installation

Disable lordodin_no_drains before enabling this fork. Review all ten startup settings, then restart Factorio. Multiplayer peers need matching settings.
